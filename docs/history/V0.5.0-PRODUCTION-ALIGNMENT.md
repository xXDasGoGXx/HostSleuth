`mjmalleo/hostsleuth:0.4.0`

`mjmalleo/hostsleuth:0.5.0`

## Live acceptance

Post-redeploy checks confirmed:

- `/api/about` reports `v0.5.0`;
- `/api/snapshot` reports schema 4 and Docker mode;
- the service remains reachable at `192.168.2.181:8787`;
- retained event history survived the redeploy, including events from hours before the upgrade;
- Optional Safe Actions remain `enabled=false` and `available=false` in Docker/default mode;
- a loopback-source query can read the Safe Action capability response;
- LAN GET/POST access to the Action Web/API still returns HTTP 403, preserving the loopback-only boundary.

## Evidence Bundle acceptance

Direct access to the Docker state directory remained blocked by the existing HomeCommander/host permission boundary and was not bypassed.

For a production-data acceptance test, the live `/api/snapshot` and `/api/events` responses were copied into a disposable `/tmp` state directory and processed with the independently verified published `v0.5.0` amd64 binary.

Results:

- binary reported `v0.5.0 (04a53f8f0f3f)`;
- preview completed successfully;
- preview included 100 recent events and zero Safe Action audit records;
- estimated uncompressed payload was about 57 KiB;
- export created only the expected files:
  - `manifest.json`;
  - `summary.txt`;
  - `snapshot.json`;
  - `events.json`;
  - `checksums.txt`;
- final ZIP permissions were `0600`;
- all embedded SHA-256 checksums verified successfully.

The disposable acceptance directory was removed after verification.
