## Included milestone

v0.6.0 contains M12 Expected Endpoint Contracts:

- read-only on-demand endpoint expectations;
- exact optional DNS-address-set comparison;
- required TCP reachability;
- optional TLS modes `ignore`, `present`, `verified`, and `forbidden`;
- optional native systemd active-state expectation;
- optional container running-state expectation;
- deterministic Expected-vs-Observed checks and first proven mismatch;
- CLI, API, and Web UI Expectations workflow.

M12 design and security boundary remain documented in `docs/design/M12-EXPECTED-ENDPOINT-CONTRACTS.md`.
