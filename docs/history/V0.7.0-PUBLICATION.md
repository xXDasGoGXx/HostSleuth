## Included milestone

v0.7.0 contains M13 DNS Detective + Admin Console v1.

DNS Detective:

- system resolver plus up to four explicitly supplied resolver IPs;
- DNS port 53 / IP-only custom resolver boundary;
- normalized A/AAAA/CNAME or PTR evidence;
- per-resolver duration and bounded errors;
- address-scope classification;
- bounded resolver runtime context;
- deterministic agree/diverge/partial/single outcomes;
- bounded split-view hint;
- CLI, API, and dedicated Web UI.

Admin Console v1:

- desktop navigation rail;
- global Quick Target bar;
- Diagnose / Expectations / DNS routing;
- browser-local recent targets;
- browser-local density preference;
- keyboard `/` target focus;
- responsive fallback navigation;
- reduced-motion and stronger focus behavior.

CI also gained cancellation of obsolete in-progress PR/ref runs.
