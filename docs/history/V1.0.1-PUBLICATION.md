## Included patch scope

- problem-first Overview launcher and normal URL handling in Quick Target;
- anchored Incident Lens and Reboot Story presentation;
- bounded browser-side evidence summaries across major investigative views;
- consistent generic PASS / WARNING / FAILED / UNKNOWN presentation;
- compact host identity/current-state rail;
- continue-investigating handoffs between existing deterministic workflows;
