# v1.4.0 — Replay

Date: 2026-10-16
Owner request: "I don't want the same as everyone else's stuff, I want something like 'oh wow this
is great', even if it means a revamp." A prototype on the real week of the OMV host was accepted
("definitely cooler"), then: build it in as the live home screen.

## What it is

Replay is the new default view and first tab. The host's containers are drawn as an engineering
sheet (cyanotype): one box per container grouped by compose project, a connector per container
showing its bind class and published ports, a title block that doubles as the revision table, and
a legend. A seven-day tape below rewinds the drawing; Previous/Next change, Play the week and
Latest drive it. One plain sentence says what was happening at the selected moment, leading with
the longest-unhealthy container. Tapping a container shows its week and hands off to Container
Story (`window.hostSleuthOpenContainer`). Deep links such as `#overview` still open their view.

## Engine

- `internal/core/replay.go`: `BuildReplay(snapshot, events)` returns parts, stacks (largest first),
  per-container state transitions, numbered events with narration and visual outage windows,
  version history and notes. Window 7 days, at most 400 events.
- Narration rules (fixed, deterministic): reboot anchored at the boot time with the kernel change
  when recorded; an all-container restart (≥4 containers and ≥60% of the health-checked ones
  entering *starting* in the same minute, not near a reboot) reads "That pattern fits a Docker
  restart."; crash with exit code; clean stop; health failure (with the autoheal note when the
  container started again within seconds and an autoheal container exists); recovery; slow start
  (>30 minutes to healthy); 1.3 update/recreate/restart summaries; package and configuration
  changes grouped by minute.
- Connectors carry the bind class only (all, LAN, local, host network, no network) and port
  numbers; a test asserts no address appears in the JSON.
- `docker inspect` template gains `com.docker.compose.project` (read with `with`/`index` so a
  missing label is not an error); the Evidence Bundle aliases it.
- `GET /api/replay` (503 until the first snapshot); `/assets/fonts/` serves the embedded B612 and
  B612 Mono WOFF subsets and `OFL.txt` with fixed names (traversal returns 404). No external loads;
  CSP unchanged.

## Test data

`internal/core/testdata/replay_week.json` is one real week of the OMV host with every container,
image and network renamed, the host renamed `homelab` and addresses replaced by `192.0.2.10`: a
reboot onto a new kernel, three all-container restarts, a VPN container that took 15 hours to
become healthy with a crash in the middle, a health failure fixed by autoheal, a backup container
still failing, two updates and a clean restart. The tests pin the narration lines and kind counts
(reboot 1, docker 3, crash 1, slow 1, unhealthy 7, recovered 5), the reboot anchor, connectors and
the absence of addresses. The README and FEATURES screenshot is this fixture served by a dev build.
